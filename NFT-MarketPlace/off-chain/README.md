# NFT Marketplace User Guide

This guide explains how users can interact with the off-chain NFT Marketplace platform.

## Connect Wallet

Before using the marketplace, the user must connect a wallet through the **CONNECT WALLET** button.

Wallet connectivity follows the **CIP-30** standard, and the platform currently supports these wallets:

- **Lace**
- **Nami**
- **Eternl**

Once connected, the user can browse listed NFTs, mint new NFTs, and sell NFTs already available in their wallet.

## HOME Page

![HOME page](manual%20pictures/Home.png)

The **HOME** page displays the NFTs currently listed for sale on the marketplace.

From this page, the user can:

- Buy an NFT that is listed for sale
- View available NFTs on the marketplace
- Update the price of a listed NFT if they are the owner
- Cancel the sale of a listed NFT if they are the owner

## SELL Page

![SELL page](manual%20pictures/Sell.png)

The **SELL** page allows the user to list NFTs that already exist in their wallet for sale on the marketplace.

From this page, the user can:

- View NFTs available in their connected wallet
- Select an NFT they want to sell
- Set a sale price and list the NFT for sale

## MINT Page

![MINT page](manual%20pictures/Mint.png)

The **MINT** page is used to mint new NFTs.

From this page, the user can:

- Create and mint a new NFT
- Provide the NFT information required by the platform
- Add a new NFT to their connected wallet after minting

## User Flow Summary

The typical user journey on the platform is:

1. Click **CONNECT WALLET**
2. Connect a supported CIP-30 wallet: **Lace**, **Nami**, or **Eternl**
3. Use **HOME** to browse or manage listed NFTs
4. Use **SELL** to put wallet-owned NFTs on sale
5. Use **MINT** to create new NFTs
